# Go Go Ackman: SNES recompilation guide for Windows and SDL3

> Historical bring-up guide. The scope statements and validation results describe the initial scaffold; consult the root README and later reports for current features.

## Scope and results

Local build and smoke testing completed; see [evidence and limitations](RESULTADOS.md). The experimental executable is `build-ninja/AckmanRecomp.exe`.

This directory contains an initial port project, C sources, CMake, scripts, and a validation protocol. Analysis of the supplied ROM generated 89 AOT variants from nine roots across three banks. This does not establish complete decompilation, validated boot, or cycle accuracy.

SNESRecomp emits low-level C rather than recovering the original source. The framework is [RetroPortingToolkit/SNESRecomp](https://github.com/RetroPortingToolKit/snesrecomp), maintained by mstan and contributors. Elliott Tate maintains [DKC2Recomp](https://github.com/elliotttate/DKC2Recomp), which uses it. Do not confuse similarly named projects.

Pinned revision: `e119994bcde03dec95f9ebaeeda305d72a6668b2`. The APIs and examples below refer to that revision.

| Requirement | Delivered at this stage | Still requires Ackman validation |
| --- | --- | --- |
| 65c816 → C analysis | Official CLI, initial CFG, local output | Dynamic coverage, indirect calls, and all M/X modes |
| Windows/SDL3/CMake | Official host integration and local build | Interactive and long-duration testing |
| External ROM | SHA-256 before execution; no embedded image | Final package audit |
| Adaptive View | Concrete viewport and PPU calls with scene availability bounds | Streaming callback and scene-specific sprites |
| Native widescreen | Concrete integration point | Camera, HUD, and culling reverse engineering |
| Savestates | Runtime snapshot and host-specific resume PC | Corruption, atomic writes, mod/MSU identity |
| MSU-1 | Register core, data, and linked mixer | Game music driver, serialization, and FMV |
| Mods | `.snesmod` loader, directory, and hooks | Verified Ackman packages/functions |

CMake flags alone cannot promise generic widescreen or FMV. See [integration requirements](MODS_MSU_WIDE.md).

## 1. Prerequisites

### MSVC

- Windows x64, Visual Studio 2022 Build Tools with Desktop development with C++, Windows SDK, and AddressSanitizer components.
- Git, Python 3.10+, and CMake 3.24+ on PATH.
- An MSVC-compatible SDL3 development package, or the runner's hash-pinned CMake download. Do not use SDL2 headers/libraries.

Open Developer PowerShell for VS 2022. With vcpkg installed:

```powershell
vcpkg install sdl3:x64-windows
```

Configure with `-DCMAKE_TOOLCHAIN_FILE=C:/vcpkg/scripts/buildsystems/vcpkg.cmake`, or `-DSDL3_DIR=C:/SDL3/cmake` pointing to the directory containing your package's `SDL3Config.cmake`.

### MinGW-w64

Use one MSYS2 UCRT64 or MINGW64 environment for both compiler and SDL3. Do not mix MSVC, MINGW64, and UCRT64 libraries. In a UCRT64 terminal:

```sh
pacman -S --needed mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-cmake mingw-w64-ucrt-x86_64-ninja mingw-w64-ucrt-x86_64-SDL3 git python
```

Rust is optional: scripts select SNESRecomp's Python analyzer. Its Rust analyzer is an optional optimization.

## 2. Analysis and C generation

From the project root in PowerShell:

```powershell
.\scripts\bootstrap.ps1 -Rom 'R:\ChatGPT\Go Go Ackman (Japan).sfc'
```

Bootstrap downloads the framework when needed, pins its commit, and regenerates C. For subsequent regeneration:

```powershell
python scripts/regen.py --rom 'R:/ChatGPT/Go Go Ackman (Japan).sfc'
```

`rom_identity.txt` defines the fixed identity. Do not change its hash merely to bypass rejection. Different revisions require their own analysis/validation. A `.smc` with an optional 512-byte copier header and identical normalized image receives the same SHA-256.

Measured ROM data:

```text
mapping: LoROM, Japan, no coprocessor, no SRAM
actual normalized size: 1,310,720 bytes (1.25 MiB)
header declares 2 MiB capacity; do not pad the file artificially
reset: $00:8000; native NMI: $00:81BC
CRC32: 26fb2d11
SHA256: e8a33b6c8e15cf0aa60e9694471a51926fb97ad895d4714384c6abff28a33a1f
```

`recomp/bank00.cfg`, generated by the official probe:

```text
bank = 0
auto_vectors
tier_down_stubs
```

This seed does not describe every jump table, WRAM routine, or DB/DP/M/X dependency. The effective generation command is:

```powershell
python external/snesrecomp/snesrecomp_cli.py generate `
  --rom 'R:/ChatGPT/Go Go Ackman (Japan).sfc' `
  --cfg-dir recomp --out-dir src/gen --funcs-h recomp/funcs.h `
  --project-root . --cfg-roots --analysis-backend python `
  --expected-sha256 e8a33b6c8e15cf0aa60e9694471a51926fb97ad895d4714384c6abff28a33a1f
```

`bank*_v2.c`, `dispatch_v2.c`, and the manifest are generated under `src/gen/`, ignored by Git. Do not edit generated C; promote roots/bounds in CFGs and regenerate. Actual declaration syntax, shown only as an instructional example **not validated for Ackman**:

```text
func NomeVerificado 9dac end:9db0 entry_mx:0,0
```

Derive bounds from disassembly/traces rather than guesses. Follow indirect calls, long jumps, REP/SEP/XCE changes, and returns. For conventional LoROM addresses >= `$8000`, the basic offset is `((bank & 0x7f) << 15) | (address & 0x7fff)`. Use the mapper for aliases/mirroring, especially with this non-power-of-two ROM size.

Enable `SNESRECOMP_TIER2_CAPTURE=1` during exploration and inspect fallback manifests before expanding analysis. Emitting `0 LLE variants` only describes emitted variants; it does not prove no fallback occurs later. Never conceal gaps with fabricated return values.

## 3. C/SDL3 wrapper architecture

```text
main.c → snesrecomp_desktop_main (official SDL3 host)
  ├─ resolve file → SHA-256 → AckmanVerifyLoadedRom → SnesInit
  ├─ SDL3 events / keyboard / gamepads / viewport
  ├─ RtlRunFrame → kGameInfo.run_frame → bridge → generated C dispatch
  │                                      └─ 65816 fallback when needed
  ├─ draw_ppu_frame → PPU/HDMA → SDL3 texture/renderer
  └─ SDL3 audio stream → S-DSP + MSU-1 mixer
```

`src/main.c` instantiates `SnesDesktopHostGame` and calls the real `snesrecomp_desktop_main`, avoiding a copied host implementation that would drift from upstream. SDL/window/events/guest execution live in:

- `external/snesrecomp/runner/src/desktop/host_main.c`;
- `external/snesrecomp/runner/src/desktop/sdl_compat.h`;
- `src/game_rtl.c`, handling frames/interrupts;
- `src/port_extensions.c`, handling viewport/telemetry.

CMake forces `SNESRECOMP_SDL_BACKEND=SDL3`. At this historical stage `config.ini` selected SDL, 48 kHz audio, and aspect preservation. The optional upstream OpenGL presenter was compiled but not selected. SDL3 window creation has no x/y arguments, initialization returns booleans, and audio uses streams; do not mechanically substitute SDL2 APIs. See [SDL3 CreateWindowAndRenderer](https://wiki.libsdl.org/SDL3/SDL_CreateWindowAndRenderer).

### Scheduling limitation

`game_rtl.c` derives from the official bring-up template: execute guest slices, deliver NMI when NMITIMEN permits, then draw scanlines with HDMA. A frame model is not evidence of cycle accuracy. A nominal 262×1364 budget and one NMI per frame cannot alone model short scanlines, interrupts during code, H-IRQ, DMA, or overscan.

Beam HDMA is disabled because template rasterization already runs it; both paths would consume tables twice. Before qualification, validate/replace scheduling with real game events, `snes_master_clocks_until_irq`, `snes_master_clocks_until_line`, and bridge deadlines. E/I flags and native/emulation vectors also matter. VSync/Windows clocks pace presentation rather than define SNES cycles.

### States

`RtlSaveSnapshot`/`RtlLoadSnapshot` and in-memory runtime APIs cover serialized CPU/hardware, including WRAM, PPU, VRAM, CGRAM/OAM, APU/SPC/DSP, and DMA. Check `common_rtl.c` and `snes/*_saveload` at the pinned revision, especially new fields.

`state_save_extra`/`state_load_extra` add little-endian `g_resume_pc` bytes. `fwrite(&snes, sizeof snes, ...)` is invalid because the structure contains pointers/host resources.

Shift+F1 saves Slot 1 and F1 loads; F7 opened the state menu at this stage. Save/load at stable frame boundaries with synchronized audio. State generation lets the host discard audio from the old timeline.

At this stage upstream file writes directly opened the destination. Power-loss resilience requires a same-volume temporary, flush/close, and atomic replacement (`MoveFileExW` on Windows), preserving prior state on failure. Add a versioned envelope with ROM SHA-256, build ID, mod identity, bounded size, and payload checksum. Validate before mutation and test rollback. Do not qualify MSU states before implementing the extension record described in the integration guide; this historical build did not meet that gate.

## 4. Dynamic ROM loading

The host resolves an argument/cache/picker, verifies identity, reads with `ReadWholeFile`, calls `src/rom_guard.c` on the same bytes, then calls `SnesInit`. The guard normalizes headers, requires the expected size, computes framework SHA-256, and rejects mismatches. Runtime uses ROM bus data; checking a pathname and executing embedded assets is insufficient.

`src/rom_guard.c` rechecks loaded bytes rather than trusting a previous pathname check. Verification precedes guest execution.

There is no `#include "rom.h"`, `xxd -i`, ROM `.rc` resource, or full-image array. Recompiled C contains derived logic/constants; no embedded ROM does not mean no derived material. Generated files/game assets are excluded from the shareable source package. Audit final packaging and dependency licenses.

## 5. CMake and compilation

[The root CMakeLists.txt](../CMakeLists.txt) uses real helpers from the pinned revision rather than an imaginary `SNESRecomp::Core` target.

MSVC with CMake-fetched SDL3:

```powershell
cmake -S . -B build-msvc -G 'Visual Studio 17 2022' -A x64
cmake --build build-msvc --config RelWithDebInfo --parallel 6
ctest --test-dir build-msvc -C RelWithDebInfo --output-on-failure
Copy-Item config.ini build-msvc/RelWithDebInfo/config.ini
.\build-msvc\RelWithDebInfo\AckmanRecomp.exe 'R:\ChatGPT\Go Go Ackman (Japan).sfc'
```

With installed SDL3, add `-DSNESRECOMP_SDL3_FETCH=OFF` and its path or a vcpkg toolchain. Keep compiler build directories separate.

MinGW/Ninja with tools on PATH:

```powershell
cmake -S . -B build-mingw -G Ninja -DCMAKE_BUILD_TYPE=RelWithDebInfo
cmake --build build-mingw --parallel 6
ctest --test-dir build-mingw --output-on-failure
Copy-Item config.ini build-mingw/config.ini
.\build-mingw\AckmanRecomp.exe 'R:\ChatGPT\Go Go Ackman (Japan).sfc'
```

For broken Windows Python aliases, set `-DPython3_EXECUTABLE=C:/caminho/real/python.exe`. Offline builds can use predownloaded dependencies and `-DSNESRECOMP_SDL3_SOURCE_DIR=C:/fontes/SDL3-3.4.10`. CMake should confirm `SDL3 desktop backend`. Static SDL needs no SDL3.dll; shared SDL uses the helper to copy its DLL.

Distribute the validated executable, configuration, licenses, and permitted mods. Do not include `private/`, ROMs, PCM, `.msu`, or `src/gen/` in this source package. A clean installation must handle a missing compatible ROM; see later safe-picker updates for current behavior.
